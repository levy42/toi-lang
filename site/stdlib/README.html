Standard Library

The Toi standard library has two layers:

  • native modules implemented in C and imported directly, such as math, json, or socket
  • shipped Toi libraries under lib.*, such as lib.types, lib.db, or lib.http_server

Import native modules like this:

import math
json = import json

Import Toi libraries like this:

import lib.types
db = import lib.db

Module Groups

  • Core: globals, numbers, strings, tables, time, URLs, UUIDs, and basic inspection
  • Files And System: files, directories, OS helpers, mmap, signals, low-level output
  • Text And Data: JSON, TOML, CSV, regex, templates, binary data, B-trees, compression
  • Networking And Concurrency: sockets, HTTP helpers, polling, coroutines, threads, contexts
  • Toi Libraries: the higher-level libraries implemented in Toi itself
